# そらいろ御翔帳（仮）

JAL修行（JGC修行）を楽しく続けるための「日本の空港スタンプラリー」PWAです。
御朱印帳 × 旅のパスポートの世界観で、空港ごとにオリジナルの名物スタンプを押していきます。

- 本体は `index.html` 1ファイル（CSS・JS込み）。外部APIなし・オフラインで動作
- 記録は端末の localStorage に保存。JSONで書き出し・読み込みできます
- 収録：定期便のある国内84空港（JALグループ就航55）

## ファイル構成

```
index.html            アプリ本体
manifest.json         PWAの設定（アプリ名・アイコン・全画面表示）
sw.js                 Service Worker（オフライン対応）
icons/                アプリアイコン（SVG元データとPNG）
.nojekyll             GitHub Pages で余計な変換をさせないための空ファイル
```

## GitHub Pages で公開する

1. このブランチを `main` にマージする（または Pages の公開元にこのブランチを選ぶ）
2. GitHub のリポジトリ画面 → **Settings** → **Pages**
3. **Build and deployment** の Source を **Deploy from a branch** にする
4. Branch で `main`、フォルダで `/ (root)` を選んで **Save**
5. 1〜2分待つと `https://<ユーザー名>.github.io/sorairo-goshocho/` で公開されます

※ 無料プランの GitHub Pages はリポジトリが **Public** である必要があります（Private で使う場合は有料プラン）。

## iPhone のホーム画面に追加する

1. **Safari** で公開URLを開く（Chrome などでは追加できない場合があります）
2. 共有ボタン（□に↑）→ **ホーム画面に追加**
3. ホーム画面のアイコンから起動すると、アドレスバーなしの全画面で開きます
4. 一度開けば、機内モードでも起動できます

## 更新を配信するとき

`sw.js` の `VERSION` を上げてからプッシュしてください（例：`v1.0.0` → `v1.0.1`）。
アプリは「キャッシュを先に表示し、裏で新しい版を取得」するので、**更新後2回目の起動**で新しい版になります。

## データについて

- 就航情報は変わります。自信のないデータには「要確認」マークを付けています。アプリ内の
  「空港データを直す」から JAL就航・離島フラグを修正し、「確認済み」にできます。
- IATAコードのない飛行場（調布・新島・神津島）は ICAO コードで表示しています。
- スタンプの図案はすべてオリジナルです。航空会社のロゴ・商標は使っていません。
